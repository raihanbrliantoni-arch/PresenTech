4. FIRMWARE ESP32
------------------------------------------------------------
Lokasi: D:\Coding\Arduino\PresenTech_alat\
- PresenTech_alat.ino (9.547 byte)
- config.h            (kredensial asli, berisi device key ptd_...)
- config.example.h    (template tanpa rahasia)

Fitur:
- WiFi STA + auto-reconnect (SSID "Raihan_2.4G"; password di config.h).
- POST /attendance dengan body {"uid":"..."} + X-Device-Key.
- UID dikirim uppercase format %02X (wajib, DB menyimpan uppercase).
- Heartbeat tiap 3 detik ke /device/heartbeat (agar perintah web cepat).
- Perintah restart dari server: baca restart_requested, kirim
  /device/restart-ack, lalu ESP.restart().
- Mode baca UID: baca scan_requested, tampilkan MODE BACA UID,
  kirim hasil ke /device/scan-result, lalu kembali ke mode absensi.
- LCD I2C 20x4 (0x27, SDA21/SCL22): tampilan default "SMK TELESANDI",
  tampilan hasil absensi.
- Buzzer pin 27: bunyi sukses / peringatan / error.
- Jendela double-tap 3 detik untuk mencegah absen ganda.
- Penanganan HTTP 201/409/404/401/403/422/429.
- Parsing JSON manual (ArduinoJson tidak terpasang di
  D:\Coding\Arduino\libraries).

Pin mengikuti referensi Done_selesai.ino:
LCD SDA21/SCL22, MFRC522 SS5/RST4/SCK18/MISO19/MOSI23, Buzzer 27.
Tidak memakai SD card, RTC, atau Ethernet.

10. UPDATE 26 OKTOBER 2026 - FITUR BACA UID DARI WEB
------------------------------------------------------------
Tujuan: Admin dapat membaca UID kartu langsung dari alat melalui
dashboard, tanpa mengetik UID manual.

Alur:
1) Admin memilih perangkat Online di menu Kartu RFID.
2) Klik "Baca UID dari Alat" -> modal konfirmasi (Oke/Batal).
3) Oke -> POST /api/devices/{id}/scan; alat masuk mode baca pada
   heartbeat berikutnya (maks. +/- 3 detik).
4) Tap kartu -> alat kirim UID ke POST /api/device/scan-result.
5) Web polling GET /api/devices/{id}/scan -> UID tampil, lalu modal
   Oke (pakai UID) / Batal (buang UID).
6) Sesi berakhir otomatis setelah 60 detik atau saat dibatalkan.

Backend:
- Migrasi 2026_10_26_101516_add_scan_fields_to_devices_table.php
  (scan_requested_at, scanned_uid, scanned_at).
- DeviceController: requestScan, scanStatus, cancelScan, scanResult,
  hasActiveScanRequest, expireScanSessions.
- heartbeatByKey: balasan scan_requested + scan_expires_in.
- routes/api.php:
  POST   /api/device/scan-result        (device key)
  POST   /api/devices/{device}/scan     (admin)
  GET    /api/devices/{device}/scan     (admin)
  DELETE /api/devices/{device}/scan     (admin)
- UID dinormalkan (RfidUid), sesi scan 60 detik, hasil disimpan
  120 detik, status perangkat Offline/Maintenance ditolak 409.

Firmware (versi 1.1.0):
- Heartbeat 3 detik.
- State scanMode terpisah dari mode absensi.
- LCD: MODE BACA UID / TEMPELKAN KARTU / PERINTAH DARI WEB.
- Setelah tap: UID TERBACA / UID / TERKIRIM KE WEB / ABSENSI AKTIF.
- Alat kembali ke mode absensi otomatis (tanpa tombol di alat).
- Batal dari web -> SCAN DIBATALKAN; timeout -> SCAN TIMEOUT.
- Saat masuk mode scan, medan RF di-reset (antenna off/on) dan gain
  diatur maksimum agar kartu yang masih HALT ikut terdeteksi.
- Pembacaan mode scan memakai WUPA (bukan REQA), sehingga kartu
  yang baru dipakai absensi tetap bisa dibaca tanpa dilepas.
- Log Serial "Mode scan aktif: menunggu kartu (WUPA)" dan
  "Scan selesai -> kembali ke mode absensi".
- WiFi diarahkan ke SSID "Raihan_2.4G" (password tidak dicetak).

Frontend:
- deviceApi: requestDeviceScan, getDeviceScanStatus, cancelDeviceScan.
- RfidPage: dropdown perangkat Online, tombol Baca UID, polling 1,5
  detik, modal Oke/Batal, batalkan sesi; simulasi UID acak dihapus.
- Pilihan siswa memakai dropdown dengan pencarian (nama/NIS/kelas),
  dikelompokkan per kelas; hanya siswa Aktif yang bisa dipilih.
- NIS dan Kelas hanya tampil (readOnly) dan otomatis dari siswa.
- UID readOnly di mode alat setelah scan; tetap bisa diketik di mode
  Manual.
- Tombol Selesai: reset UID/pilihan, bersihkan sesi scan, dan info
  bahwa alat kembali ke absensi otomatis.
- Teks mode scan: "Menunggu alat siap..." dan instruksi menunggu
  LCD MODE BACA UID (±3 detik) sebelum menempelkan kartu.
- Setelah Daftarkan berhasil, sesi scan dibersihkan di server.
- ConfirmModal mendukung onCancel untuk membersihkan sesi.
